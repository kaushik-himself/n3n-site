Dynamic Visual Reply

Review several items. Reply once.

An agent skill for multi-item reviews. Select records, edit values, and attach instructions to individual items, then send one batch of feedback to your agent.

01 / Review

Work through several items.

Use an interactive table, cards, a form, a board, or a step view to review the records together.

02 / Instruct

Give each item its own feedback.

Select records, edit values, and add an instruction to the specific item it belongs to.

03 / Submit

Send one batch to your agent.

Your selections and edits stay drafts until you submit. The agent receives the feedback with each item’s identity intact.

Submitting sends instructions to the agent. It does not directly change your tasks or source data.

Get the skill Read the README

Read-only mode can show a report without editing or feedback controls. Display and submission options depend on the host; local browser submissions do not start an agent turn by themselves.
